Tutorix submission package
==========================

Which file goes in which upload field:

1. Project Summary PDF (required, max 10 MB)
   Tutorix_Project_Summary.pdf  (3 pages: title, field, team, abstract,
   objectives, innovation, impact, screenshots, CAG/RAG diagram)

2. Project Proposal (optional, max 10 MB)
   Tutorix_Project_Proposal.pdf  (11 pages: full proposal with problem,
   objectives, all 20 tools, architecture, CAG/RAG method, security,
   innovation, evaluation results, screenshots, impact, future work, team)

3. Photos/Diagrams (optional, each image max 5 MB)
   Recommended picks:
     diagrams/architecture.png
     diagrams/rag-cag-pipeline.png
     screenshots/01-landing-hero.png
     screenshots/04-teacher-dashboard.png
     screenshots/06-worksheet-grounded-in-material.png
     screenshots/13-student-dashboard.png
     screenshots/16-mind-map.png
     screenshots/20-vocabulary-bangla-english.png
   All other screenshots in the screenshots folder can also be uploaded.
